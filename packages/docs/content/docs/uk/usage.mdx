# Використання та квоти

Сторінка «Використання» показує, скільки з плану кожного провайдера ви витратили, щоб ви бачили, наскільки близько до ліміту перебуваєте. Відкрийте її в **Settings → Usage**.

## Що ви бачите

Огляд будує статистику на основі збереженої історії сесій OpenCode для кожного провайдера, який створив відповідь асистента, зокрема для провайдерів, доданих плагінами або через власну конфігурацію API. Можна переглянути останні 7, 30 чи 90 днів або вибрати довільний діапазон дат. Для кожного провайдера також є окрема сторінка з відфільтрованою статистикою.

Для кожного підключеного провайдера з підтримкою квот OpenChamber також показує:

- скільки з поточного вікна ви використали, у вигляді смужки
- розподіл за моделями
- індикатор темпу, щоб ви могли зрозуміти, чи встигнете вичерпати ліміт

Наведіть вказівник на графік або сфокусуйте його, щоб побачити точне значення за кожен день чи для кожного провайдера. Можна обрати, які провайдери квот відображаються, а той самий підсумок квот доступний із випадного меню в заголовку застосунку.

## Підтримувані провайдери

Історична статистика працює для всіх провайдерів, записаних у ваших сесіях. Дані про квоти й залишки лімітів доступні для провайдерів, які публікують квоту, зокрема Claude, Codex, GitHub Copilot, Google, OpenRouter, Kimi, NanoGPT, z.ai, Zhipu, MiniMax, Ollama Cloud та Wafer.

Підключені провайдери з’являються після налаштування на сторінці [Провайдери](/uk/providers/), а історична статистика може залишатися й після відключення провайдера. Кільком інтеграціям квот потрібен додатковий крок — наприклад, Ollama Cloud читає файл сесії, який ви налаштовуєте окремо. Якщо дані про залишок ліміту відсутні, перевірте облікові дані квоти цього провайдера.
